# Простая игра-кликер

Простая игра-кликер, в которой игрок зарабатывает очки, нажимая на кнопку.

## 🕹️ Описание
Это мини-проект для домашних животных, в котором реализована базовая игровая механика.  
Основная цель - нажимать и увеличивать свой счет.

Игры—кликеры - это новый жанр, где игрок зарабатывает очками по кликам и быстро совершенствует программу :Ссылка на контент[ссылка на сайт:0]{индекс=0}.

## ⭐ Особенности
- Кликай, чтобы заработать очки
- Простой и минималистичный интерфейс
- Базовая логика игры
